# FFUI v0.3.3

## English

This patch release improves queue progress reporting and makes time labels easier to read while jobs move through processing and finalization.

### Improvements

- Queue cards now keep phase progress and time information in sync more consistently during processing, muxing, finalization, and audio sidecar work.
- Progress bars and compact queue views have smoother updates for active jobs.
- Time labels have better spacing in detailed and icon queue layouts, improving readability at a glance.

### Maintenance

- Updated the release workflow action versions used to build draft releases.

## 中文

本次补丁版本改进队列进度展示，并让任务在处理和收尾阶段的时间标签更易读。

### 改进

- 队列卡片在处理、封装、收尾和音频 sidecar 等阶段，会更稳定地同步阶段进度与时间信息。
- 活跃任务的进度条和紧凑队列视图更新更平滑。
- 详细队列和图标队列布局中的时间标签间距更合理，便于快速扫读。

### 维护

- 更新用于构建草稿 Release 的发布工作流 action 版本。
