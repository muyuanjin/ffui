# FFUI v0.3.2

## English

This patch release focuses on queue responsiveness, preview reliability, and safer backend command handling.

### Improvements

- Improved queue refresh behavior so rapid progress updates use the latest state without extra UI churn.
- Made preview generation and refresh scheduling more reliable, including better handling for container output previews.
- Improved the preset editor layout and supporting screenshots in the documentation.
- Streamlined several shared UI display helpers used by queue items, monitoring charts, VMAF stats, and preset fields.

### Fixes

- Fixed cases where leaving the screensaver view could keep the app in fullscreen.
- Hardened Matroska command planning and preview scheduling for edge cases around output handling.
- Added deeper validation for frontend-to-backend command payloads.
- Adjusted local Tauri builds so unsigned updater artifacts are skipped when signing keys are not configured.

## 中文

本次补丁版本重点提升队列响应、预览可靠性，并加强后端命令调用的安全校验。

### 改进

- 优化队列刷新逻辑，让高频进度更新优先使用最新状态，减少不必要的界面抖动。
- 提升预览生成与刷新调度的可靠性，包括容器输出预览的状态同步。
- 改进预设编辑器布局，并更新相关文档截图。
- 抽取并复用队列项、监控图表、VMAF 统计和预设字段中的显示逻辑。

### 修复

- 修复离开屏保视图后应用可能仍停留在全屏状态的问题。
- 加强 Matroska 命令规划和预览调度在输出处理边界场景下的稳定性。
- 为前端到后端的命令参数增加更严格的深度校验。
- 调整本地 Tauri 构建行为，在未配置签名密钥时跳过未签名的更新器产物。
