# FFUI v0.3.4

## English

This release repairs Linux AppImage packaging and collects fixes for batch compression, presets, and the queue label.

### Fixes

- Linux AppImage: the bundled `.DirIcon` entry was an absolute symlink that pointed back at the build machine, so launchers and the AppImage catalog reported a missing icon. It is now a relative link.
- Linux desktop entry: the AppImage and the deb/rpm packages now declare the `AudioVideo` category, so the app appears under a real menu section instead of an empty category.
- Windows: background `ffmpeg`/`ffprobe` helpers no longer set `DETACHED_PROCESS` next to `CREATE_NO_WINDOW`, a combination in which Win32 ignores the second flag; they are now created with the intended no-window flags.
- Batch Compress: media recovery settings now travel with the job, so a restart or crash recovery no longer falls back to defaults; media child processes stay under worker ownership, config roots and job ids stay in sync, and finished outputs are published consistently.
- Presets: saving a preset is validated end to end, and the frame-rate field accepts decimals (`29.97`), rationals (`30000/1001`) and the `ntsc`/`ntsc-film` aliases.
- External tool installs are transactional: a failed install no longer leaves a partially installed tool, and a fallback resolver handles release downloads.
- The queue tab and its empty-state badge now read "Transcode Tasks" (`转码任务`), matching what the queue holds.
- Output preview uses the container declared by the preset, and playback no longer falls back to a file that does not exist.
- The frontend bundle no longer ships unused chart libraries.

### New

- Presets that declare two-pass encoding now actually run both passes.

### Maintenance

- Rust and Tauri dependencies were refreshed.

## 中文

本版修复 Linux AppImage 打包，并集中处理批量压缩、预设与队列命名的一批问题。

### 修复

- Linux AppImage：包内 `.DirIcon` 之前是指向构建机的绝对符号链接，导致启动器与 AppImage 目录判定图标缺失；现在改为相对链接。
- Linux 桌面项：AppImage 与 deb/rpm 现在声明 `AudioVideo` 分类，安装后出现在真正的菜单分类中，而不是空分类。
- Windows：后台 `ffmpeg`/`ffprobe` 不再把 `DETACHED_PROCESS` 与 `CREATE_NO_WINDOW` 一起设置——Win32 在这种组合下会忽略后者；现在按预期的隐藏窗口标志创建。
- 批量压缩：媒体恢复设置现在随任务一起持久化，重启或崩溃恢复不再回落到默认配置；媒体子进程保持在工作线程所有权下，配置根与任务 id 保持同步，完成的输出会被一致地发布。
- 预设：保存预设会做端到端校验，帧率字段接受小数（`29.97`）、分数（`30000/1001`）以及 `ntsc`/`ntsc-film` 别名。
- 外部工具安装改为事务式：安装失败不再留下半装状态，并新增了发布下载的兜底解析。
- 队列标签页与空态徽标改为「转码任务」（Transcode Tasks），与实际承载的内容一致。
- 输出预览使用预设声明的容器，播放不再回退到不存在的文件。
- 前端产物不再打包未使用的图表库。

### 新增

- 声明两遍（two-pass）编码的预设现在会真正执行两遍。

### 维护

- 更新了 Rust 与 Tauri 依赖。
