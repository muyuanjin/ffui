# FFUI v0.3.6

## English

Convert video, audio and images through the same preset-based queue, with separate parameter and output settings for mixed-media workflows.

### Highlights

- Add or drop audio and images directly into the queue, including folders. Structured presets manage single-file output; custom command templates support other FFmpeg recipes. Manual jobs do not apply Batch Compress's minimum-saving threshold.
- **Parameter settings** offers a unified preset or separate presets by input type. **Output settings** offers a unified format or separate formats by the preset's target output type, including extracting audio from video. Choosing a format does not change codecs; incompatible combinations report diagnostics.
- **Add command** accepts a complete FFmpeg command for advanced multi-input, multi-output, generated-source and analysis tasks. Arguments are passed directly, without shell expansion. Application-fed/received media through stdin/stdout is not supported.
- Audio cards show metadata and available cover art. Preview audio and images directly, with compatible cached copies when native decoding fails. Unknown work duration uses indeterminate progress.
- Media Info can inspect audio files, not only video and image files.
- The Linux AppImage embeds update information and ships a `.zsync` next to it, so AppImageUpdate and AppImageLauncher can update it in place and download only the changed blocks instead of the whole image. Check it with `./FFUI_0.3.6_amd64.AppImage --appimage-updateinfo`.

### Fixes

- Parameter and output preferences persist in the same application data directory across executable rebuilds. Saves preserve unknown settings and reject conflicting edits or replacements that would discard unsupported data. Sparse configuration imports preserve existing output-policy semantics.
- Queue recovery protects unreadable history and rejects unavailable settings instead of executing with placeholder defaults. Recovery cannot recreate history that has already been deleted. Saved execution snapshots preserve output semantics and concurrency classification after preset edits or deletion.
- Managed audio/image tasks can wait and continue from the beginning, including rapid wait/continue actions. Video retains two-pass encoding and supported segmented recovery. Transparent commands do not automatically replay and may leave partial external outputs after cancellation.
- Output-path actions use recorded output addresses, never the input path. Dismissing a format dropdown leaves Output settings open.
- Preview cleanup reclaims abandoned application-owned workspaces without deleting active conversions or unrecognized files.
- Linux in-app updates use signatures that match the shipped AppImage.

## 中文

视频、音频和图片可使用同一套预设队列转码，并通过独立的参数设置与输出设置处理混合媒体任务。

### 重点更新

- 音频和图片可直接添加或拖入队列，也支持文件夹。结构化预设托管单文件输出，自定义命令模板支持其他 FFmpeg 处理方案；手动任务不套用批量压缩的最低节省门槛。
- **参数设置** 支持统一预设或按输入类型选择预设。**输出设置** 支持统一格式或按预设目标输出类型指定格式，包括从视频提取音频。选择格式不会更换编码器，不兼容组合会显示诊断。
- **添加命令任务** 接受完整 FFmpeg 命令，支持高级多输入、多输出、生成源和分析任务。参数直接传给 FFmpeg，不进行 shell 展开；不支持应用通过 stdin/stdout 供给或接收媒体数据。
- 音频卡片展示元信息及可用封面，音频和图片可直接预览；原生解码失败时提供缓存兼容副本。总工作量未知时显示不定进度。
- 媒体信息可以打开音频文件，不再只支持视频与图片。
- Linux AppImage 内嵌更新信息并附带 `.zsync`，因此 AppImageUpdate、AppImageLauncher 可以就地更新，且只下载变化的区块，不再重新下载整个镜像。可用 `./FFUI_0.3.6_amd64.AppImage --appimage-updateinfo` 查看。

### 修复

- 使用相同应用数据目录时，重新编译 EXE 仍保留参数及输出偏好。保存保留未知设置，拒绝冲突编辑及会丢弃不支持数据的整体替换；稀疏配置导入保持已有输出策略语义。
- 队列恢复保护不可读取的历史，拒绝使用不可用设置的占位默认值执行；已经删除的历史无法重新生成。任务执行快照在预设编辑或删除后仍决定输出语义和并发分类。
- 托管音频／图片任务可以等待后从头继续，包括快速等待再继续；视频保留双遍编码及已支持的分段恢复。透明命令不会自动重放，取消后可能留下部分外部输出。
- 输出路径操作使用已记录的输出地址，不拿输入路径替代；关闭格式下拉时，输出设置保持打开。
- 预览清理回收遗留的应用工作目录，不删除活动转换或无法确认归属的文件。
- Linux 应用内更新使用与发布 AppImage 相匹配的签名。
